Les écrans

Chaque page est du HTML et du CSS statiques, avec les jetons de charte.css. Les boutons en haut d'une page basculent entre les états à dessiner ; un lien ci-dessous ouvre directement un état. Les écrans sont prévus pour l'ordinateur et le téléphone (réduire la fenêtre pour le voir). Les classes (.bouton, .champ, .bandeau, .etat, .fenetre…) sont celles à reprendre dans React.
